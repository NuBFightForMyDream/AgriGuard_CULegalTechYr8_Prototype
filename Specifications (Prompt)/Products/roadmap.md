# Roadmap

## Phase 0 — Foundation

Auth/RBAC, organizations, farm/product master data, purchase request, offer, order state machine, audit timeline, sample data, online demo deployment with Google sign-in ([deployment.md](../Technical/deployment.md))

**Exit:** create and track a basic multi-fruit transaction end-to-end in demo mode, from a public URL

## Phase 1 — MVP assurance

Matching rules, manual allocation, HarvestLock, delivery lots, GradeProof checklist, settlement preview, dispute workflow, verified AgriTrust dashboard

**Exit:** no overbooking; every key action has evidence and audit trail

## Phase 2 — Decision support

OR-Tools allocation, harvest baseline forecast, payment/pickup event scoring, notifications, scenario analysis

**Exit:** optimizer passes constraint tests; forecast reports interval and backtest metrics

## Phase 3 — AI upgrades

Learning-to-Rank, calibrated risk models, computer vision assist, legal RAG, anomaly signals

**Exit:** offline metrics, model registry, human review, rollback and monitoring are operational

## Phase 4 — Scale

Logistics VRP, mobile offline capture, integrations with payment/ERP/weather, multi-region deployment

## Cross-phase guardrails

Do not label deterministic demo output as trained AI; do not auto-enforce adverse decisions from a score; preserve model/data versions; conduct privacy, fairness and security review before production
